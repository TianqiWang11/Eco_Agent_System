# 平台启动说明

1. 双击项目根目录的 `启动平台.bat`，等待约 20 秒。
2. 浏览器自动打开 `http://127.0.0.1:8000`，可直接操作 UE 数字孪生和 AI 助手。
3. 使用结束后双击 `停止平台.bat`。

UE 工程、打包程序和官方 Pixel Streaming 运行环境默认从
`D:\TQ_Projects\UE_data` 读取；换路径时设置 `CHEBALING_UE_DATA_ROOT`。

局域网其他电脑访问 `http://本机IP:8000`。

默认采用兼容流畅模式：`1440×810 / 50fps / 最高 12Mbps`，鼠标不会被网页锁定。

操作数字孪生时，先点击画面，再使用 `WASD` 移动；按住鼠标左键拖动视角。点击门户上方“返回初始场景”可复位，重新打开门户也会自动从初始场景进入。
